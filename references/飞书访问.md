# 飞书访问与自动登录

> 触发：打开或登录飞书、飞书扫码、飞书文档、飞书消息。未命中禁止读本文件。

- 专用 Chrome 无头会话：调试端口 `9223`，配置目录 `D:\codex-feishu-profile`（登录态持久，勿迁移）。
- 未登录/过期：直接生成飞书扫码登录二维码图片发给用户，扫码确认后自动继续。不要反复问是否要登录。
- 二维码：打开 `https://www.feishu.cn` → 登录 → 切到「二维码登录」→ 保存 canvas 为 PNG → Markdown 图片展示（正斜杠绝对路径）。
- **正文要滚到底**：docx 是虚拟滚动，只读首屏会得出「正文只有两节标题、口径全在 Figma」这类假结论。逐屏下滚、累积取全文，再判断有没有口径要求；连接器标签里读空或截图超时同理，改无头 Chrome 复用 `9223` 登录态取 DOM。
- Cursor：可用内置浏览器截图展示二维码；持久登录仍走 9223 专用会话，不要把登录态迁到临时目录。
