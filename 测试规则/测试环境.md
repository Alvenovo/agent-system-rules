# 测试环境操作

> 触发：测试环境登录、造数、写入、验证码、多端自动登录。未命中禁止读本文件。

写入/数据变更类操作：动手前先说明具体操作、对象、影响范围、是否需要清理；**用户同意后才执行**；只读查看不受限。测试数据默认保留供校验，不主动清理；清理先提方案，经同意后执行。禅道仍严格只读，除非用户明确要求写回。

## 凭据只留在名册

口令、手机号、验证码只存在于账号名册文件（路径见项目级 `AGENTS.md`）。会话交接、记忆、用例正文、证据目录、脚本源码里一律写「见账号名册」，需要值时运行时从名册取。

- **验证码与登录二维码截图**：读完在同一条命令里删掉，不进证据目录。
- **抓包与 DOM dump 落盘前掩码**：按键名过滤 `pass|pwd|token|secret|captcha`。被动抓包日志的 `postData` 同样带口令，只挡主动请求会漏。落盘后 grep 一次口令面值，确认零命中。
- **从名册取值用 ASCII 字符类** `[!-~]{4,40}`：`\S+` 会把行内中文备注一起吞进去当口令提交，回「密码错误」还以为口令变了。
- **口令连错 2 次就停手上报**，第 3 次不再试。先分清两种原因：① 脚本取错了值（看取到的长度与首尾字符）；② 这个号确实不在这轮改动里（直接问一句「这个号改了吗」）。
- 名册文件本身的改动走系统级「不可再生文件安全写入」；改完逐条正则复核残留。

## 测试数据创建与保留

- **创建前必须先确认**：数据名称、字段值、用途、所在页面、影响范围完整告知，并询问“是否直接在测试环境中新建”；确认后才执行。
- **创建后保留**；清理仅在用户明确要求时进行。
- **可识别可追溯**：新建数据统一命名 `wwd测试_YYYYMMDD`（如 `wwd测试_20260915`；需区分对象时加短后缀，如 `wwd测试_20260915_商品`）；登记项目《测试数据台账.md》附查看路径；存量旧命名数据同步改名/重建属写入操作，先确认。
- **创建后主动汇报**：名称、页面/接口、状态、查看路径，必要时附截图。
- **修改他人创建的数据、影响共享数据或正式流程**，先说明、经用户同意后执行。

## 测试环境多端自动登录

- 按项目级 `AGENTS.md` 或 `.cursor/rules/` 中《测试环境入口清单》顺序依次登录；登录态有效直接复用。
- **多账号并行隔离**：先判被测系统把登录态放在哪，再决定拆不拆进程。
  - 存在 Cookie / sessionStorage / localStorage（跨 tab 共享）：每个账号各占一个独立浏览器会话——独立 browser context（CDP `Target.createBrowserContext` / Playwright context）、独立 profile（各自 `--user-data-dir`）或独立浏览器实例。同一 Chrome 多开无痕窗口共用一份 Cookie 存储，不算隔离。
  - 只存在页面内存（SPA 的 vuex / redux）：同一 profile 多标签即可，每 tab 一份身份，**依次登录**；身份读内存态，读共享 localStorage 会串号。并发启动失败只说明要改依次登录，不说明这系统做不到多号在线。
  - 开几个窗口听用户。但「这一步是谁做的」属于取证必要条件时（人工陪测按卡、责任归属），主动提议拆独立进程。
  - 单账号单端仍按上一条复用已有持久登录态，不为此重复登录。
- 过期按清单顺序逐个重登；每端先图形验证码、确认后触发短信、再索取短信验证码，**不要乱序、不要一次性索取全部验证码**。
- 只读查看不受登录限制；写操作仍遵守上文写入确认。

## 验证码获取与发送（固定方法，不再试错）

1. 图形验证码取图：页面内 `fetch(验证码URL)` → `arrayBuffer` → `btoa` 保存 PNG；页面内 base64 `img` 直接取 `dataURL`。
2. 放大：Python PIL 8 倍 LANCZOS（脚本若存在：`%USERPROFILE%\.codex-build\upscale.py` 或项目内 `.codex-build/upscale.py`），只放大不裁剪。
3. 图形验证码识别：模型自行识别并填写，最多 **3 次**（填错或过期则刷新换图再识）。前 3 次不要把图发给用户。
4. 3 次都没对：再把当前放大后的验证码图用 Markdown（正斜杠绝对路径）发给用户，等用户回填后填入；取不到独立验证码图时再整页截屏。用户回填后若仍错/过期，重新取图，再从第 3 步走（先自己识 3 次）。不换别的取图方式。
5. 短信验证码：触发发送成功后直接向用户索取，填入登录。不要求用户先认图形验证码。
